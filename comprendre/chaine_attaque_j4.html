Ce qu'il faut retenir

  

    
1 · PORTS
Ce que Docker publie, la salle le voit
"3143:3143" veut dire toutes les cartes réseau. "127.0.0.1:3143:3143" réserve la boîte au poste.

    
2 · INJECTION
Le message est une donnée
Une « note interne » dans texte peut piloter le modèle. Le prompt durci aide, il ne suffit pas.

    
3 · APPROBATION
Un lien signé se lit, il ne se devine pas
La signature de /webhook-waiting/…?approved=true protège tant que l'e-mail reste privé.

    
4 · BASE
200 € passe le plafond
CHECK (montant <= 200) n'arrête que ce qui dépasse. Les défenses doivent se cumuler.
