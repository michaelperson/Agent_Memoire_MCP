Ce qu'il faut retenir

  

    
1 · INITIALIZE
D'abord ouvrir une session
initialize renvoie l'en-tête Mcp-Session-Id ; sans lui, les requêtes suivantes reçoivent 400 « Server not initialized ».

    
2 · BEARER
Le jeton est vérifié avant tout
Avec authentication: bearerAuth, une requête sans le bon jeton reçoit 403 « Authorization data is wrong! », avant même le protocole MCP.

    
3 · TOOLS/LIST
Les descriptions partent chez le client
Nom, description et inputSchema de chaque outil : c'est le texte que lira le modèle de l'hôte. Une description piégée y entre aussi (jour 3).

    
4 · TOOLS/CALL
Le serveur exécute, il ne réfléchit pas
Pas de modèle côté serveur : arguments.email remplit $fromAI('email') et la requête SQL part telle quelle.
