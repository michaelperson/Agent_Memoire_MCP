1 · BRANCHEMENT
L'outil passe derrière l'approbation
accorder_geste est relié à l'entrée Tool du nœud Send Email (Human review), qui est lui-même l'outil de l'agent.

    
2 · MESSAGE
L'humain doit voir ce qu'il approuve
{{ JSON.stringify($tool.parameters, null, 2) }} ; avec {{ $tool.parameters }}, l'e-mail affiche « [object Object] ».

    
3 · DÉLAI
Pour un outil, expiré = refusé
Avec limitWaitTime, l'outil ne s'exécute pas. Attention : un nœud « Send and Wait » dans le flux principal, lui, laisse continuer.

    
4 · BASE
La dernière barrière reste la base
CHECK (montant > 0 AND montant <= 200) refuse un geste trop élevé, même approuvé par erreur.
