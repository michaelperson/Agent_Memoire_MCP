# Jour 4 – Trame de la démonstration (5 minutes, questions comprises)

Objectif : montrer **un agent qui travaille seul, se souvient, partage ses outils et sait s'arrêter**.
Pas de slides : on montre n8n, une commande et une boîte e-mail.

| Temps | Ce que vous montrez | Ce que vous dites (une phrase) |
|-------|---------------------|-------------------------------|
| 0:00 – 0:30 | Le canevas de votre agent | Le problème métier que l'agent résout pour l'agence |
| 0:30 – 1:30 | Un message envoyé, la réponse, l'exécution | Comment il se déclenche, quelle limite d'itérations, que se passe-t-il en cas d'erreur |
| 1:30 – 2:15 | Un deuxième message du même client | Ce qu'il retient, combien de temps, comment le client le fait effacer |
| 2:15 – 3:00 | Une demande de geste + l'e-mail d'approbation | Ce qu'il ne fera jamais sans un humain |
| 3:00 – 3:45 | L'attaque la plus grave subie ce matin, rejouée | Ce qui a cassé, ce que vous avez corrigé, la preuve que c'est corrigé |
| 3:45 – 5:00 | Questions | |

## Avant de passer

- [ ] Messages de démonstration prêts dans un fichier (copier-coller, pas de frappe en direct)
- [ ] Boîte du responsable vidée, onglet *Executions* ouvert
- [ ] Plan B : captures d'écran si le réseau ou le modèle ne répond pas

## Ce que le groupe observe (formatif, sans note)

- L'agent se déclenche sans clic dans l'éditeur
- La mémoire est justifiée (type, durée, effacement)
- L'action sensible est validée par un humain qui voit ce qu'il approuve
- Une attaque réelle est rejouée et bloquée
